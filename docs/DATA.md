# 데이터 구성과 n 수 (v3, 2026-10-14)

## 분할 규칙
- **dev** = Brackish 원본 `train.txt` + `valid.txt`의 모든 프레임. 임계값(t, τ)과 프롬프트·DINO 설정은 여기서만 정한다.
- **test** = 원본 `test.txt`의 모든 프레임. 설정을 고정한 뒤 한 번만 평가한다.
- 정답: AAU CSV (6종 박스). 분할 목록에 있지만 AAU에 없는 프레임은 "생물 없음"(`empty_by_absence`).
- 분할 목록 밖의 410프레임(한 영상의 일부)은 어느 쪽에도 넣지 않는다.

> ⚠️ **원본 분할은 프레임 단위 무작위 분할**이라 89개 영상이 **모두 dev와 test 양쪽에 등장**한다.
> 인접 프레임은 거의 같은 화면이므로 dev에서 정한 값이 test 화면에 미리 맞춰질 수 있다.
> 이 실험은 학습을 하지 않고 dev에서 정하는 값이 스칼라 몇 개(t, τ_e, τ_c)뿐이라 영향은 작지만,
> 결과 보고 시 "영상 단위로 분리된 test가 아님"을 각주로 밝힌다.
